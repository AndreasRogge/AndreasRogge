# Andreas Rogge

I build and run security operations stuff that has to work at 3am: detections, hunting, automation, and the boring but necessary engineering around it.

## What I work on
- **Microsoft Sentinel**: KQL detections, analytics rules, workbooks, content lifecycle
- **Microsoft Defender XDR**: hunting, incident workflows, device/user investigations
- **Automation**: Logic Apps / SOAR patterns, enrichment, response playbooks
- **Identity & access in the real world**: operational guardrails, least-privilege pain points, MSSP setups

## Current focus
- Turning “noisy logs” into **actionable detections** (and documenting why they exist)
- Building **repeatable SOC processes**: onboarding, tuning, validation, response
- Sharing field lessons so other teams don’t repeat the same mistakes

## Repositories you’ll probably care about
- **SentinelKQL**: practical KQL for Sentinel use cases  
- **AdvancedHuntingKQL**: queries for Defender Advanced Hunting  
- **DefenderForEndpoint**: scripts around Defender for Endpoint APIs  
(If you want, I can suggest a better structure + naming so these feel like one coherent toolbox.)

## How I like to work
- Prefer small, readable building blocks over “one giant query”
- Every detection needs: intent, data sources, blind spots, false positives, validation steps
- If it can’t be tested, it’s a guess
